# Project Brief: Industrial Systems Manufacturing Suite

## 1. Project Overview
The objective is to design and develop a premium, engineering-focused digital platform for a high-end industrial machinery manufacturing corporation. The suite will provide B2B clients and internal operators with tools for fleet management, diagnostics, and technical documentation, all while maintaining a visual identity of precision and reliability.

## 2. Brand Identity & Design Principles
- **Core Values**: Reliability, Precision, Engineering Excellence, Durability, Professionalism.
- **Visual Style**: Modern Industrial. Clean lines, generous whitespace, and a high-end B2B aesthetic. 
- **Avoid**: SaaS/Startup tropes, glassmorphism, bright gradients, or cartoonish illustrations.

## 3. Design System (Industrial Premium Framework)
- **Primary Palette**: Marine Ink (#324E64) - depth and stability.
- **Accent**: Clementine Gold (#F3BA43) - functional highlights and precision.
- **Typography**: Hanken Grotesk (Modern geometric sans-serif).
- **Geometry**: 16–20px rounded corners; 8px grid system.
- **Elevation**: Very soft, minimal shadows to maintain a "flat but tactile" feel.

## 4. Key Platform Features (Anticipated)
- **Fleet Dashboard**: High-level overview of machinery status and uptime.
- **Asset Diagnostics**: Deep-dive telemetry data for individual units (temperature, vibration, pressure).
- **Maintenance/Work Orders**: Management system for engineering repairs and scheduling.
- **Technical Library**: ISO standards, specifications, and CAD documentation.
- **Operations Console**: Real-time control interface for machinery operators.

## 5. Technical Requirements
- **Responsive Web**: Primary focus on Desktop (Operator consoles) with mobile support for field engineers.
- **Performance**: High-speed rendering for real-time data visualizations.
- **Accessibility**: High contrast ratios and clear typography for industrial environments.

## 6. Project Roadmap
- **Phase 1: Foundation**: Create design system and UI component library (Completed).
- **Phase 2: Core Workflows**: Design Fleet Status and Diagnostic screens.
- **Phase 3: Operations**: Design Maintenance and Inventory management flows.
- **Phase 4: Analytics**: Implement advanced data visualization and reporting.
